# 覆盖矩阵模板（新项目复制这份，实例化即可）

> **T0 约束**（`SKILL.md`）：穷举是硬约束 —— 交付前必须证明"全维度 × 全状态 × 全边界值"都判过，漏一行 = 交付失败。
> 用法：复制到 `<项目根>/策划/`，按项目把 `{}` 里的东西填成具体值；枚举**必须用脚本产出**（`tools/probes/enumerate-*.py|ps1`），⛔ 不许手写。
> 方法本体 = `patterns/full-coverage-audit.md`（维度定义 / 科学依据 / 判据 / 闸门）。

## 1. 实体清单 `策划/实体清单.tsv`（脚本生成）

列：`维度 | 实体 | 载体/路径 | 出处 | 状态数 | 判据类型 | 归属片`

判据类型取值：`脚本断言` / `参考物比对` / `并排图` / `阻塞(登记)`。
维度取值：`D1资源 D2几何 D3材质 D4UI D5动画 D6特效 D7音乐 D8音效 D9碰撞 D10逻辑 D11输入 D12流程 S1数值 S2性能 S3设置`。

## 2. 状态矩阵 `策划/状态矩阵.tsv`

列：`维度 | 实体 | 状态/事件 | 边界值 | 期望表现(出处) | 实测 | 结论 | 证据`

- 状态取**枚举值 + 边界值**（阈值上下各一、0、上限、超界），⛔ 不取"任意帧"。
- `期望表现` 必须带出处（参考物 `文件:行` / 资源文件 / 规格条款）。
- `结论` 只允许三种：`一致` / `不一致(差在哪)` / `允许的差异(→ 差异登记)`。

## 3. 差异登记 `策划/差异登记.tsv`

列：`是什么 | 为什么 | 出处 | 何时消除` —— 四要素缺一 = 未登记 = 不许交付。

## 4. 枚举脚本的契约（每个维度一个，或一个大脚本按维度分组）

输出必须是**稳定排序的 TSV**（同一份盘 ⇒ 同一份输出，可 diff），至少能回答：

- 这个维度**一共多少个实体**（行数 = 覆盖率的分子 / 分母）；
- 每个实体的**载体路径**（判"引用是否指对"）与**出处**；
- 每个实体的**状态数**（展开后的行数）。

## 5. 实例化步骤（顺序不许跳）

1. 定参考物 A 与它的**载体在哪**（原版客户端 / 资源包 / 源码 / 规格书）；拿不到 ⇒ 先走降级链并登记。
2. 写枚举脚本 → 生成 `实体清单.tsv`（**先只看行数对不对，别急着判**）。
3. 展开 `状态矩阵.tsv`（对象 × 状态 × 边界值）。
4. 逐行给判据（脚本 / 参考物 / 并排图），先跑完所有**可脚本判**的行（便宜的先跑）。
5. 装三条闸门 + 维度覆盖率进 `tools/verify.ps1`。
6. 按维度切片派执行者，逐片勾满；每片回报必须带「勾了多少行 / 还剩多少行红」。
7. 全表零 `不一致` ⇒ 才允许出现"完成"字样。
