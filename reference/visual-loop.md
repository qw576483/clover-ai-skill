# 视觉闭环（visual oracle loop）：把"看起来像"换成"一个数字 + 一份待办"

> **这是"能不能 1:1"的最后一块拼图**：把**差异本身**变成**可执行待办**喂回执行者，让它能**迭代到没有差异**。

## 一、核心思想

> **"像素级完美是渲染输出的属性，不是源码的属性。"** ⇒ **diff 必须是目标函数**：执行者最小化"**测量出来的误差**"，而不是靠抽象猜测。
> ⇒ **"像不像"不能靠人眼看、也不能靠模型看，要靠 diff 数字 + delta 清单。**

## 二、闭环形状

```
采集基线(ground truth) ──► 实现/改代码 ──► 渲染 ──► diff ──► 达标?
      ▲                                                       │ 否
      └────────── 把精确 delta 清单喂回执行者 ◄────────────────┘
```

**基线怎么来**（必须可重复拍摄，否则噪声当回归）：渲染**参考物那一侧**并保存 **截图 PNG + 解析后的布局 / 几何数据**（后者让"不一样"变成"改哪里"）；确定性保障：**固定分辨率与缩放**、**冻结动画**、**等待字体就绪**、固定渲染模式 / DPI；每个关键状态各自一条基线（菜单 / HUD / 交战 / 结算 / 死亡观战 / 暗态）。

## 三、判定：三个信号**同时**满足才算过

| 信号 | 机制 | 作用 |
|---|---|---|
| **像素 diff** | **`clover-tools/visual-verify/visual-diff.py`**（确定性 YIQ 距离 ≈ pixelmatch；参数 `--threshold`（默认 0.1）/ `--max-diff-pixels`（默认关）/ `--aa-policy`（默认 `count` = 每个像素都算，`suppress` = 不计抗锯齿）；输出 side-by-side + 差异叠加图 + 分段待办） | 量化像素漂移 |
| **结构相似** | `SSIM` | 抓"位移"这类原始像素比会低估的漂移 |
| **几何/布局 diff** | 按元素比 **包围盒 + 关键属性**（位置 / 尺寸 / 颜色 / 字号） | **把"不一样"变成"改哪里"** |

参考容差：`maxDiffRatio ≤ 0.001`（≤0.1% 像素）、`minSsim ≥ 0.99`、`pixelmatchThreshold 0.1`。三个容差均由同一个脚本判定（`--max-diff-ratio` / `--max-diff-pixels` / `--min-ssim`，任一不达标即 FAIL；用法见 `clover-tools/visual-verify/README.md`）。

## 四、输出必须是"待办清单"，不是分数

```
[OFF] 场景__分辨率__状态    diff=0.333%   ssim=0.9845
- 元素A: 尺寸 0,-4px; 上内边距 10px（应为 12px）; 圆角 6px（应为 8px）
- 元素B: 位置 x+2px; 字号 13px（应为 12px）
```

**这张清单才是喂给执行者的东西** —— 它把"再改改"变成"改这三个数"。（可把 diff 叠加图一并给模型看；但**判定仍然是 diff 数字，不是模型的观感**。）

## 五、怎么挂到 agent 上（三个通道，按需组合）

> **diff 是"贵动作"，只在批次边界跑**：批量改完 → 预演（跑 diff，拿 delta 清单）→ 批量修 → 再跑一轮。⛔ 改一处就跑一次 diff = 把最贵的动作重复 N 次。
> ⚠️ 但这不是次数上限：**一直跑到容差内 / 与 A 原版零不一致为止**；"diff 跑了几轮"从来不是收工理由。

| 通道 | 挂点 | 做法 |
|---|---|---|
| **A. 钩子（首选）** | **批次边界** | 跑**一次** diff，把 **delta 清单注入上下文**让执行者**批量修**。⛔ 不做"每次保存即 diff" |
| | `Stop` | diff 超容差 ⇒ **拒绝结束**（必须带防死循环标记） |
| **B. 工具（可选）** | MCP / CLI | 把 `capture_baseline` / `visual_diff` 做成工具，让执行者在批次边界自己调 |
| **C. 守护进程（可选）** | 会话外 | 监视文件变更 ⇒ **攒到"一次批次结束"再重 diff**；漂移时派发一次限定范围的新 run（默认只提示，不自动改） |

**防死循环**：`Stop` 钩子必须带"本轮已拦过"的标记（如标记文件）。

## 六、必须承认的边界（**诚实目标 = 感知容差内，不是字节一致**）

**跨渲染引擎做到字节一致，物理上不可能**（web → 原生；同理 GoldSrc → Unity）。诚实目标是"感知上落在容差内"：

| 对象 | 判据 | 能不能到 |
|---|---|---|
| **数据 / 数值 / 公式 / UI 坐标** | `diff = 0`（数值层面） | **能到 1:1** |
| **渲染画面（跨引擎）** | 三信号落在**容差内**；要"字节一致"必须先复刻对方的渲染管线 | 容差内可达 |

### 六.1 ★ 参考图必须来自**同一场景**（跨关卡外推 = 无效依据，且方向会全错）

**规矩（三条）**：① **先认身份，再量数** —— 参考图 / 基线图**自身**要能说出它是哪座场景 / 哪一关，认不出就别用它下结论；② **反证句** —— 任何"原版是 X"的结论都要能回答「**这张图凭什么代表这个场景**」，答不上来 = 待核；③ **优先用同一素材包内部的自证**（素材自己的对称性 + 同场景实机图），⛔ 不要拿**别的场景**的图来补。

### 六.2 ★ 取景对齐：原版是**斜视**相机时，正交平视要用**非等比正交投影**复现（⛔ 不是缩放内容根）

**症状**：用 `orthographicSize = max(H/2, W/2/aspect)` 恰好铺满整屏 ⇒ 场地底沿 = 屏幕底沿 ⇒ 底部关键元素被 UI 挡住。

**★ 判据口径**：屏上的「格」**不一定是正方形** —— **横向 px/格 与纵向 px/格 必须分别量**，⛔ 不能拿一个当两个用（拿横向值回算纵向会得出"场地放不下"的死结论）。

**改法**：`Matrix4x4.Ortho(-halfW, halfW, -halfH, halfH, near, far)`，`halfW` 按画宽算、`halfH` 按"纵向格数 ÷ 压缩比"算，再把相机平移到场地底沿落在目标行。**新增常量一律带出处。**

**★ 为什么必须是投影矩阵，⛔ 不能"把内容根 `localScale.y` 压缩"**：投影矩阵**参与 `ScreenToWorldPoint`** ⇒ 点击落点 / 落位指示 / 跟随 UI 全部自洽；缩放内容根则**屏幕 → 世界失配** ⇒ **点哪错哪**。

**可失败的判据**（取实机自报读数）：横 / 纵向 px per world 的**实测值必须等于量到的两个值**；场地底图行区间正确；底部关键元素在 UI 上沿**之上**；**最高节点 ≥ 0**（顶部无裁切）。再配**像素交叉校验**（截图上草色末行 vs 场景普查末行，差 ≤ 1 px）⇒ 两条独立路径同答才算过。

**诚实边界（必须登记）**：均匀压缩 ≠ 原版**斜视透视**（近大远小）；要 1:1 复刻那一点需**斜视相机**，另立一片。场地之上原版有背景美术、我方没有 ⇒ 是**美术缺口**，登记为差异，⛔ 不要当黑屏 bug 去瞎调。

## 七、和本项目（Unity）对应起来

- 基线：**跑原版截同机位帧**，或用原版资源 + 固定相机位姿渲染一帧（位姿写进基线记录）。
- 采集我们的：**固定分辨率 / 固定渲染模式 / 冻结动画**后截图（同机位、同画幅）。
- 判定：**像素 diff + SSIM + 几何 diff**；几何 diff 直接用已有的坐标 / 包围盒数据。
- 输出：delta 清单（"这把枪的 viewmodel 位置 y+3px""这个面板圆角差 2px"）。
- 迭代：改 → 再渲染 → 再 diff，直到容差内或登记为"渲染管线差异，不可消除"（**按批次**，⛔ 不是改一处跑一次）。

## 八、联络图（contact sheet）：**可选** —— 一批表现类一次看

> **什么时候用**：一次交付里有**多个**表现类界面要一起看（≥4 屏）⇒ 拼一张图看一次，比逐张读图省一个量级。
> **什么时候不用**：只有 1~2 屏 ⇒ **直接截一张看一眼**（⛔ 不要为了"规范"去拼图 / 建索引表 / 建分格表）。
> ⛔ 该由脚本判的（数值 / 几何 diff）⛔ 不要拉 AI 看图 —— AI 只看汇总。

### 8.1 采集（**一次跑完，不逐项进出 Play**）

- **能同框就同框**：把同一时刻的多个对象一次拉远框进画面（零拼接、最省）；
- **互斥状态分帧采**：活着 / 死亡 / 通关这类物理上不可能同屏 ⇒ 逐帧截所需小区域（`ScreenCapture.CaptureScreenshotAsTexture()` + `ReadPixels(rect)`，或宿主截图命令）再拼版。「一个画面放不下就切」的正确形态是**切帧**，不是切场景。
- ⚠️ **改 / 拍必须分两次执行**：`CaptureGameView` 取的是**上一帧**已渲染的缓冲，不会为你重绘 ⇒ 同一次调用里"改参数 → 立刻截"拍到的是改动之前的状态，序列逐张错位一格。术后自检：两张**没有状态变化**的连续帧如果不同，就是滞后。
- ⚠️ **别用 `Time.timeScale = 0` 帮忙**：它冻得住渲染，但引擎自带定时服务不吃它；且冻结期间客户端收不到快照，解冻后污染采样。

### 8.2 拼版与判定（**用代码做，别手摆**）

- 用 `Pillow` 之类把各格拼成大图，**每格烧上** `格号 + 状态名 + 关键数值`，格间留分隔线，角落放采集时间；需要对应关系时输出 `index.tsv`（**给机器读的，不是要你填的表**）。
- **工具（已实现，⛔ 不手摆）**：拼版 = `clover-tools/visual-verify/compose-contact-sheet.py`；窗口级截屏 = 同目录 `capture-editor-window.ps1`（编辑器以管理员身份启动、外部置顶被 UIPI 挡住时，用引擎 `Editor/capture-editor-screen.cs` 的 `run_script` 入口在进程内采）。用法与判据见 §8.6。
- **判定**：① 脚本按格做**确定性 diff / 数值断言** → 逐格 `PASS / FAIL`；② **AI 只读整张图一次**（聚类 / 摘要 / 滤渲染噪声）；③ 只有 `FAIL` 的格才去看那一格的**原始大图**。
- ⛔ **红线**：**时间序列 / 手感 / 动画节奏 / 音效时机**不许用拼版代替（只能逐帧比或由人给基线）；**每格必须来自真实运行**（烧的数值要能对上日志）；**检测不许变成 AI 看图**（判定永远是脚本数字）。

### 8.6 采集与拼版的判据资产（用法 + 判据）

**① 窗口级截屏** —— OS 层像素，采的是**用户真正看到的画面**（含编辑器叠加的组件图标 / Gizmos / 选中高亮，这些不在游戏后缓冲里），与 `Screenshot.CaptureToFile`（帧末取后缓冲）互补，⛔ 不互相替代。

| 入口 | 位置 | 何时用 |
|---|---|---|
| `capture-editor-window.ps1` | `clover-tools/visual-verify/` | 外部（PowerShell）采窗口像素 |
| `EditorScreenCapture.Info/Raise/Drop/Shot/Gizmos/Freeze` | 引擎 `Editor/capture-editor-screen.cs`（`run_script --entry CloverEngine.Editor.EditorScreenCapture.Shot`） | 编辑器以**管理员**身份启动时（UIPI 挡住外部置顶），在编辑器**进程内**采 |

| 参数（PS1） | 默认 | 说明 |
|---|---|---|
| `-Out` | 必填 | 目标 `.png`（非 `.png` 直接拒绝） |
| `-TitleMatch` | — | 窗口标题**正则**（忽略大小写），按面积取最大匹配 |
| `-EditorPid` | 0 | 限定进程；与 `-TitleMatch` **至少给一个** |
| `-TimeoutSec` | 15 | 等窗口出现（0 = 单次尝试） |
| `-X/-Y/-W/-H` | — | 窗口内相对矩形裁剪（四个一起给） |
| `-Focus` / `-TopMost` / `-Desktop` | off | 还原 / 置顶 / 改走桌面合成（遮挡时可采到别的窗口） |
| `-AllowMultiMonitor` | off | 多显示器**默认拒绝**（坐标口径含糊） |
| `-MinMeanRGB` | 2.0 | 退化阈值 |

判据（失败一律 **exit 非 0**，⛔ 不许静默出黑图）：窗口找不到 / 超时 = `3`；最小化且未 `-Focus` = `3`；多显示器未 `-AllowMultiMonitor` = `5`；`PrintWindow` 自报失败 = `6`；**全黑或纯色**（`uniqueColors<=1` 或 `meanRGB < -MinMeanRGB`）= `4`，此时 `<Out>` 不产出（诊断副本写 `<Out>.rejected.png`）；裁剪框越界 / 参数非法 = `2`。成功时打印 `hwnd / rect / uniqueColors / meanRGB / bytes / sha256`。

**② 联络图拼版** —— `clover-tools/visual-verify/compose-contact-sheet.py`：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--shots` | 必填 | 目录 / glob / 单个文件；逗号或分号分隔，可重复（目录与 glob 内部 `sorted()` 定序） |
| `--cols` | 4 | 列数 |
| `--labels` | — | 分号分隔的 `[格号=]状态名[\|类别\|关键数值]`（带 `\|` 时须三段齐全），烧在格下 |
| `--out` | 必填 | 联络图 PNG |
| `--index` | `<out 去扩展名>.index.tsv` | 索引表列：`格号 / 截图来源 / 状态 / 类别 / 关键数值` |
| `--title` | — | 顶部标题：**采集时间 / 构建标识由调用方传入**（工具不自动烧时间戳，否则破坏确定性） |
| `--cell-size` | 480x320 | 每格图像框 |

判据：缺任一张图 = **exit 4 且一个字节都不写**（⛔ 不半发布）；标签数量不匹配 / 格号越界 = `2`；依赖缺失 = `3`。每格坐标 / 尺寸 / 居中全由 `--cols` 与 `--cell-size` 算出、缩略图固定 `LANCZOS` ⇒ **同输入两次跑，图与索引的 SHA256 相同**（脚本自带打印这两个 SHA）。

⚠️ **写同类脚本要照抄的两条**：① `--shots <目录>` 与 `--out` 落在同一目录时，**输出文件不算输入**（否则第二遍把第一遍写的图纳入输入 ⇒ 格数变、SHA 全变，看起来像"工具不确定"）。② Python 的 `stdout` 在重定向下编码可能不是 UTF-8 ⇒ 路径里的非该编码字符会让 `print` 在**文件已写好之后**抛 `UnicodeEncodeError`（假红），显式 `sys.stdout.reconfigure(encoding="utf-8", errors="backslashreplace")` 即可（⛔ 不要去改被验源码的编码）。
